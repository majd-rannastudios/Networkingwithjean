# Brand assets

Drop the Ranna logo here as **`logo.svg`** (preferred) or `logo.png`.

Every page loads `/brand/logo.svg` and falls back to a text wordmark if the
file is missing, so the app works either way — but the real asset should be in
before anything goes in front of a client.

The logo sits on Abyssal Black `#080035`, so supply the **white / reversed**
version. Any height works; it is rendered at 26px tall on phones and scales on
the projector view.
